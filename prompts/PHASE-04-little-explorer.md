# Phase 04 — Little Explorer Content

Status: **PLANNED**

## Objective
Expand age 3–5 into a useful early-learning brain-play experience using the existing lightweight mechanics.

## Content goals
Add a small curated set covering:
- shape sorting
- colour sorting
- big/small
- count 1–5
- simple repeating patterns
- same/different
- simple animal/habitat matching
- basic visual memory
- simple story/order concepts where reading is minimal

## Design rules
- Very little reading.
- No stressful timer.
- Large touch targets.
- Friendly visual language without excessive animation.
- Incorrect attempts give gentle guidance/return, not harsh punishment.
- Reuse existing puzzle engines instead of inventing one engine per activity.
- Content should improve recognition, classification, memory, sequencing and simple reasoning—not just drill facts.

## Knowledge exposure
Lightly introduce age-appropriate nature, numbers, everyday objects and language concepts. Do not imitate school worksheets.

## Out of scope
- Older age groups.
- Deep academic content.
- Cloud sync.
- Heavy reward/meta systems.

Do not execute until Phase 3 is ACCEPTED and the architect marks this phase READY. Finish executed work at `REVIEW` and STOP.
