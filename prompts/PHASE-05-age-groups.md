# Phase 05 — Age-Adaptive Challenge Sets

Status: **PLANNED**

## Objective
Expand MIND VAULT beyond Little Explorer while keeping one shared game architecture.

## Age groups
### 6–8 — Young Explorer
Introduce basic arithmetic, sequences, categories, simple logic, visual memory, nature, vocabulary, story order and simple route/planning tasks.

### 9–12 — Young Thinker
Introduce arithmetic reasoning, pattern combinations, spatial reasoning, deduction, reading comprehension, classification and multi-step problems.

### 13–17 — Challenger
Introduce multi-rule logic, planning, deduction, mathematical/scientific reasoning, rule changes and optimization.

### 18+ — Mind Vault
Use the full challenge set: memory, logic, deduction, planning, rule mutation, abstract reasoning and knowledge-assisted problems, without relying excessively on reaction speed.

## Architecture rule
Age changes challenge style, presentation, reading level and pressure—not separate applications or separate engines.

Reuse the same mechanics whenever possible:
- sort
- match
- sequence
- memory
- choose/reason

Add a new mechanic only when a real cognitive interaction cannot be represented cleanly by the existing set.

## Difficulty rule
Age group provides the starting envelope; actual recent performance adjusts difficulty inside that envelope.

## Out of scope
- Deep curriculum coverage.
- Competitive leaderboards.
- Cloud sync.
